        BUSINESS ANALYSIS PROJECT

THE BUSINESS PROBLEM
--------------------
How can a growing retail business manage orders, returns, and refunds
without relying on multiple disconnected Excel trackers?

As order volumes increase, separate departmental files can create:

  • Duplicate or inconsistent information
  • Manual report preparation
  • Limited visibility into order status
  • Difficult refund tracking
  • Delayed identification of operational issues

The business needed a clearer and more centralized way to monitor the
complete order lifecycle.


THE QUESTION
------------
How can we improve the existing process so that Operations, Warehouse,
Customer Support, Finance, and Management can work with consistent
information and monitor key performance indicators more easily?


THE PROPOSED SOLUTION
---------------------
The project proposes a centralized reporting and dashboard solution
for the retail order lifecycle.

The solution brings together information related to:

  ORDER → SHIPMENT → DELIVERY → RETURN → REFUND

Business users can then monitor operational performance through
interactive dashboards instead of manually combining multiple reports.


HOW WE APPROACHED THE PROBLEM
-----------------------------
1. UNDERSTAND
   Reviewed the existing order, return, and refund process and
   identified the teams involved.

2. ANALYSE
   Documented the current AS-IS process and identified operational
   gaps such as manual reporting and fragmented information.

3. DEFINE
   Converted business problems into clear business and functional
   requirements.

4. DESIGN
   Designed the TO-BE process and proposed a centralized reporting
   approach.

5. REPORT
   Defined dashboards, KPIs, filters, and reporting requirements
   for different business users.

6. VALIDATE
   Defined acceptance criteria to confirm that the proposed solution
   addresses the original business requirements.


KEY BUSINESS USERS
------------------
  Operations       → Order processing and status
  Warehouse        → Shipment and return verification
  Customer Support → Customer cases and return requests
  Finance          → Refund processing
  Management       → KPIs and operational performance


WHAT THE SOLUTION SHOULD PROVIDE
--------------------------------
  • Centralized order visibility
  • Return and refund tracking
  • Pending order monitoring
  • Pending refund visibility
  • Operational KPI reporting
  • Filtering by relevant business dimensions
  • Management dashboards
  • Reduced manual reporting effort


KEY KPIs
--------
Examples of the proposed reporting metrics include:

  • Total Orders
  • Pending Orders
  • Delivered Orders
  • Return Rate
  • Refund Rate
  • Pending Refunds
  • Average Processing Time
  • Daily / Monthly Order Volume

PROJECT OUTCOME
---------------
The result is a structured Business Analysis case study showing how
a business problem can be analysed, documented, converted into
requirements, and translated into a practical reporting solution.

The project focuses on the BA thinking behind the solution:

  PROBLEM → ANALYSIS → REQUIREMENTS → PROCESS → SOLUTION

It is designed as a practical portfolio project demonstrating
requirements gathering, process analysis, documentation, stakeholder
thinking, KPI definition, and solution design.

WHY THIS PROJECT MATTERS
------------------------
A dashboard alone does not solve a business problem.

The important part is understanding:

  WHAT is going wrong?
  WHY is it happening?
  WHO is affected?
  WHAT does the business actually need?
  HOW should the improved process work?
  HOW will we know the solution works?

This project demonstrates that process from problem identification
through requirements and solution design.
